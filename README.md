# Agentic Intelligence

## Architecture & Workflow

![Agent Workflow](assets/workflow.png)

### System Workflow
1. **Counselor Agent**: Interacts with the user, asking targeted questions dynamically based on previous responses.
2. **Q&A Exchange (JSON)**: Encapsulates questions and user answers into structured JSON payloads.
3. **Agent Orchestrator**: Coordinates and delegates tasks to specialized sub-agents.
4. **Reasoning & Cognitive Agents**: Concurrently analyze responses from reasoning and cognitive perspectives.
5. **Report Agent**: Synthesizes insights and findings from the reasoning and cognitive agents.
6. **Final Report**: Generates and delivers the comprehensive final assessment report.
